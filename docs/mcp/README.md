# GitHub MCP Integration

This directory contains documentation for integrating the GitHub Model Context Protocol (MCP) server securely with Google Antigravity and other environments.

## Documentation

*   [**Production Runbook**](./github-mcp-antigravity-production-runbook.md): Detailed guide for configuring, securing, and operating the GitHub MCP server in production. Start here.

## Quick Start (Antigravity)

1.  **Read the Runbook:** Familiarize yourself with the authentication and security requirements.
2.  **Generate a PAT:** Follow the instructions in the runbook to generate a Fine-grained Personal Access Token.
3.  **Configure Client:** Use the `npx` configuration provided in the runbook. Do **NOT** commit your token.
